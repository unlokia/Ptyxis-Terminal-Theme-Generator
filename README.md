(Tested on Ubuntu 26.04 only):
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Google Gemini made this for me :-)

Open the html file in your favourite browser, customise your theme colours, name the theme, then click
[“Export .palette File”] button, and finally copy the .palette file to:

~/.local/share/org.gnome.Ptyxis/palettes

... (or use ptyxis --install-palette filename.palette) to select it inside Ptyxis preferences.

Your theme should now be listed in Ptyxis preferences.
